# WEARCOOL

A modern, responsive clothing store landing page built with Next.js and React. WEARCOOL features editorial fashion sections, collection navigation, product highlights, wishlist interactions, shopping bag notifications, and a responsive footer.

## Tech Stack

- Next.js
- React
- Tailwind CSS via CDN
- Google Fonts: Epilogue and Manrope
- Material Symbols

## Getting Started

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

```bash
npm run dev    # Start the development server
npm run build  # Create a production build
npm run start  # Start the production server
```

## Project Structure

- `app/` - Next.js App Router files and client interactions
- `public/imgs/` - Static assets served by Next.js
- `index.html` - Preserved page markup and Tailwind configuration source
- `.gitignore` - Ignores dependencies, build output, logs, and local files

# WEARCOOL

[![Next.js](https://img.shields.io/badge/Next.js-000000?style=for-the-badge&logo=next.js&logoColor=white)](https://nextjs.org/)
[![React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)](https://reactjs.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

A modern, responsive clothing store landing page built with Next.js and React. WEARCOOL delivers an immersive shopping experience with editorial fashion sections, collection navigation, product highlights, wishlist interactions, shopping bag notifications, and a responsive footer.

---

## ✨ Features

- **Editorial Fashion Sections** – Curated content showcasing the latest trends.
- **Collection Navigation** – Intuitive browsing across product categories.
- **Product Highlights** – Spotlight on featured items.
- **Wishlist Interactions** – Add or remove items from a personal wishlist.
- **Shopping Bag Notifications** – Real‑time feedback when items are added to the bag.
- **Responsive Footer** – Fully adaptive layout across all devices.

## 🛠 Tech Stack

- **[Next.js](https://nextjs.org/)** – React framework for production.
- **[React](https://reactjs.org/)** – Component‑based UI library.
- **[Tailwind CSS](https://tailwindcss.com/)** – Utility‑first CSS framework (via CDN).
- **[Google Fonts](https://fonts.google.com/)** – Epilogue and Manrope.
- **[Material Symbols](https://fonts.google.com/icons)** – Icon set.

## 🚀 Getting Started

### Prerequisites

- Node.js (v14 or later)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/wearcool.git
   cd wearcool
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📜 Available Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Starts the development server. |
| `npm run build` | Creates an optimized production build. |
| `npm run start` | Starts the production server. |
